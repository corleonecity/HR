🔑 OAuth Integration

This app uses OAuth 2.0 to securely connect Discord and Roblox accounts.

Discord OAuth

Users authenticate via Discord to verify their server membership.

Scope: identify, guilds
Redirect URI: https://corleonecity.github.io/SwordArtOnline/

Roblox OAuth

After Discord login, users link their Roblox account to earn GP.

Scope: openid, profile
Redirect URI: https://corleonecity.github.io/SwordArtOnline/
Client ID: 1529843549493669743

How the OAuth Flow Works:

1. User clicks "Login with Discord" → Discord OAuth → Returns user data
2. User clicks "Connect Roblox" → Roblox OAuth → Returns Roblox user data
3. System links both accounts and stores GP balance in Firebase
4. User can submit GP donation requests with screenshot proof
